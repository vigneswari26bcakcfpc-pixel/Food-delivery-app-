📱 Project Preview

FoodieGo provides a clean and attractive interface with an orange-themed design, making the application feel energetic and food-focused.

✨ Features
🏠 Home Screen
Discover popular restaurants
Search for food and restaurants
Browse food categories
View restaurant ratings and delivery times
🔐 Login & Account
Mobile number login
Password authentication
Create a new account
🍕 Restaurant & Menu
View restaurant details
Check ratings and delivery time
Browse menu items
View food prices and descriptions
Add individual items to cart
🛒 Shopping Cart
View selected food items
Change quantities
Calculate subtotal
Display delivery charges
View total amount
📦 Order Confirmation
Order confirmation message
Order ID
Estimated delivery time
Track order option
🗺️ Order Tracking
Track the delivery location
View order status
Follow the order from confirmation to delivery
❤️ Favorites
Save favorite restaurants and food items
👤 Profile
Manage user account and preferences

🎯 Project Goal

The main goal of FoodieGo is to create a simple, attractive, and easy-to-use food ordering experience where users can find their favorite food, order it quickly, and track their delivery.
